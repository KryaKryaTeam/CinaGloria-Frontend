> [!WARNING]
> This project is currently in the **MVP stage**. Features may be unstable, and the UI is subject to frequent updates during development.

---

## 🛠 Tech Stack

* **Framework:** [Next.js 15+](https://www.google.com/search?q=https://nextjs.org/) (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS + [shadcn/ui](https://www.google.com/search?q=https://ui.shadcn.com/)
* **State Management:** React Hooks / Context API
* **Testing:** Vitest + React Testing Library
* **Package Manager:** [pnpm](https://www.google.com/search?q=https://pnpm.io/)

---

## 🚀 Quick Start (Local)

Ensure you have **pnpm** installed on your machine.

### 1. Installation

```bash
pnpm install

```

### 2. Environment Setup

Create a `.env` file in the root directory:

```bash
NODE_ENV=development
NEXT_PUBLIC_BACKEND_BASE_URL=http://localhost:4000/v1
NEXT_PUBLIC_BACKEND_SOCKET_URL=http://localhost:4001
NEXT_PUBLIC_GOOGLE_CLIENT_ID=your_id
NEXT_PUBLIC_GITHUB_CLIENT_ID=your_id

```

### 3. Development Mode

```bash
pnpm run dev

```

The application will be available at `http://localhost:3000`.
